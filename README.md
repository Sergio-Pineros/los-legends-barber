# Los Legends Barber

A custom Shopify theme for Los Legends Barber, built in Liquid.

The theme extends a standard Shopify Online Store structure with custom sections made for the brand, including story and about pages, a sizing section, and product listing sections, so the shop can present its services and products in its own voice instead of a stock template.

## Structure

- `layout/` — theme layout
- `templates/` — page templates
- `sections/` — custom and standard theme sections
- `snippets/` — reusable fragments
- `assets/` — styles, scripts, and images
- `config/` — theme settings

## Working on it

Upload or connect the repository in the Shopify theme editor, or work locally with the Shopify CLI:

```bash
shopify theme dev
```
